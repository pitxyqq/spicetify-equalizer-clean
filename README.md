# Equalizer Clean

Equalizer Clean adds a compact equalizer panel to Spicetify.

Features:

- Simple and advanced equalizer modes
- Bass boost styles
- Built-in presets
- Saved configurations
- Right-click the playbar button to toggle the equalizer

The advanced controls are fitted to the equalizer bands exposed by Spotify. Settings are saved locally in Spotify and are not shared with other users.

## Install manually

Copy `equalizer-clean.js` to your Spicetify `Extensions` folder and add it to your extensions configuration, then run `spicetify apply`.
